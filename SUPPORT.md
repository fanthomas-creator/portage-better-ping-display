# Support

Before opening an issue, read [the user guide](docs/USAGE.md), confirm that the launched game was built with the mod, and check the declared Horizon revision.

For a bug report, include the mod version, Horizon revision, operating system, native build integration, steps to reproduce and a short relevant error excerpt. Remove account information and tokens from logs.

The mod displays server-provided latency. An unchanged value, a local value of zero or a server-specific update interval is not necessarily a mod bug.

Report problems with the original Fabric mod to its own project. This repository maintains the Rust port only.
